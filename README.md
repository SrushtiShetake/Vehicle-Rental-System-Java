# Vehicle Rental System Using Core Java

## About the Project
A console-based Java application that manages vehicle rentals, customer details, vehicle availability, and rental cost calculations.

## Technologies Used
- Core Java
- OOP Concepts
- ArrayList
- Eclipse IDE

## Features
- Display available vehicles
- Rent and return vehicles
- Calculate rental costs
- 10% discount on car rentals of 5 days or more
- Additional ₹50 per day for bikes with helmets

## OOP Concepts
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Method Overriding

## How to Run
1. Import the project into Eclipse.
2. Open `Main.java`.
3. Run as **Java Application**.
